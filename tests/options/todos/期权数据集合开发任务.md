# 数据集合开发任务

## 任务目标

确保每个期权的数据接口都能使用，并且能够在数据集合页面中能够获取到尽可能完整的数据。

因为每个期权的数据集合都不完全一样，所以可以一个一个数据集合进行，不用批量进行。

## 任务要求

1. 所有期权数据接口都需要有对应的 Provider 和 Service
2. Provider 需要正确配置 akshare 函数名、参数映射、字段信息等
3. Service 需要正确注册到服务注册表
4. 所有集合需要在元数据配置中注册
5. 测试所有接口能够正常获取数据
6. 需要数据集合的页面能够访问，数据是正常的，不能是空
7. 更新数据-> API 更新需要能够正常打开，不报错
8. API 更新里面的更新或者批量更新功能需要时正常的，能够使用，更新数据到数据集合里面

### 验收标准

1. 使用自动化测试框架 playwright 访问每个期权的数据集合，确保网站是可以访问的不报错，如果报错，就修复；
2. 确保每个数据集合的页面中，数据不是空的；如果是空的，就继续点击数据更新->API 更新->更新或者批量更新，获取数据；之后重新刷新数据集合页面，看数据是不是空的；需要保证这个数据不是空的；
3. 如果数据集合页面现在已经存在数据了，就测试一下 数据更新->API 更新->更新或者批量更新，获取数据，看看这个对话框是不是能访问，更新数据是不是正常，如果不正常，就修复。
