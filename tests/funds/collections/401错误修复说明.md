# 基金数据集合 401 错误修复说明

## 🐛 问题描述

- *错误**: `GET <http://localhost:8000/api/funds/collections> 401 (Unauthorized)`

- *现象**: 访问基金数据集合页面时，API 请求返回 401 未授权错误，无法加载集合列表。

- *错误栈**:

```bash
AxiosError: Request failed with status code 401
  at fundsApi.getCollections (funds.ts:14)
  at loadCollections (Collections.vue:101)

```bash

- --

## 🔍 问题原因

### 根本原因

`frontend/src/api/funds.ts` 文件直接使用了原始的 `axios` 实例，而不是使用配置好的 `ApiClient`。

### 技术细节

- *错误代码**:

```typescript
import axios from 'axios'

const API_BASE_URL = import.meta.env.VITE_API_BASE_URL || '<http://localhost:8000'>

export const fundsApi = {
  async getCollections() {
    const response = await axios.get(`${API_BASE_URL}/api/funds/collections`)
    return response.data
  }
}

```bash

- *问题**:
1. ❌ 直接使用原始 `axios`，没有认证拦截器
2. ❌ 不会自动添加 `Authorization: Bearer <token>` 头
3. ❌ 后端需要认证，导致 401 错误

### 正确的做法

项目中其他 API（如 `bonds.ts`）都使用了 `ApiClient`：

```typescript
import { ApiClient, type ApiResponse } from './request'

export const bondsApi = {
  async list(params?: any): Promise<ApiResponse<any>> {
    return ApiClient.get('/api/bonds/list', params)
  }
}

```bash

- *ApiClient 的优势**:
1. ✅ 自动添加认证 token
2. ✅ 统一错误处理
3. ✅ 请求/响应拦截
4. ✅ 自动处理 401 跳转登录

## 📚 相关知识

### ApiClient vs 原始 axios

| 特性 | ApiClient | 原始 axios |

|------|-----------|-----------|

| 自动认证 | ✅ 是 | ❌ 否 |

| 错误处理 | ✅ 统一处理 | ❌ 需手动 |

| 401 跳转 | ✅ 自动跳转登录 | ❌ 不处理 |

| Token 刷新 | ✅ 支持 | ❌ 不支持 |

| 请求日志 | ✅ 详细日志 | ❌ 无日志 |

| 类型安全 | ✅ TypeScript | ⚠️ 部分 |

### ApiClient 工作原理

1. **请求拦截器**（添加认证）:

```typescript
instance.interceptors.request.use((config) => {
  const authStore = useAuthStore()
  const token = authStore.token || localStorage.getItem('auth-token')

  if (token) {
    config.headers.Authorization = `Bearer ${token}`
  }
  return config
})

```bash

1. **响应拦截器**（处理错误）:

```typescript
instance.interceptors.response.use(
  (response) => response.data,  // 自动返回 data
  (error) => {
    if (error.response?.status === 401) {
      // 跳转到登录页
      router.push('/login')
    }
    throw error
  }
)

```bash
