# 后端服务重启说明

## 🐛 问题现象

```bash
POST <http://localhost:3000/api/funds/collections/fund_basic_info/refresh> 404 (Not Found)

```bash

## 🔍 原因

后端代码已修改，但后端服务**未重启**，新的路由和功能未生效。

- --

## ✅ 解决方法

### 方法 1: 重启后端服务（推荐）

1. **停止当前后端服务**
   - 找到运行后端的终端窗口
   - 按 `Ctrl + C` 停止服务

1. **重新启动后端**

   ```bash

# 在项目根目录
   python -m app.main

# 或者使用 uvicorn
   uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
   ```

1. **验证启动成功**
   - 看到日志：`Uvicorn running on <http://0.0.0.0:8000`>
   - 访问：<http://localhost:8000/docs>

- --

### 方法 2: 使用热重载（如果已配置）

如果后端使用了 `--reload` 参数启动：

```bash
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000

```bash
则应该**自动重载**，但有时需要手动触发：

- 保存任意 Python 文件即可触发重载
- 或者重启服务

## ⚠️ 常见问题

### Q1: 重启后还是 404？

- *检查**:
1. 确认后端真的重启了（查看启动时间）
2. 确认端口是 8000
3. 确认没有其他 Python 进程占用端口
4. 查看后端日志是否有错误

- *解决**:

```bash

# 确保完全停止

pkill -9 -f "python -m app.main"

# 重新启动

python -m app.main

```bash

### Q2: 前端还是报错？

- *刷新前端**:
1. 清除浏览器缓存：`Ctrl + Shift + R`
2. 或重启前端开发服务器

### Q3: 找不到刷新端点？

- *检查导入**:

确认 `app/main.py` 已导入并注册基金路由：

```python
from app.routers import funds as funds_router
app.include_router(funds_router.router)

```bash

### Q4: 任务管理器错误？

- *检查依赖**:

```bash
pip install motor pymongo asyncio

```bash
