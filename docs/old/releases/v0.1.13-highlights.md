## 🚀 快速开始

### 1. 环境准备

```bash

# 切换到预览版分支

git checkout feature/native-openai-support

# 更新依赖

pip install -r requirements.txt

```bash

### 2. 配置 Google AI

```bash

# 在 .env 文件中添加

echo "GOOGLE_API_KEY=your_api_key_here" >> .env

```bash

### 3. 验证安装

```bash

# 测试 Google AI 功能

python tests/test_gemini_simple.py

# 启动 Web 界面

streamlit run web/app.py

```bash

### 4. 体验新功能

- 🎯 在 Web 界面中选择 Google AI 模型
